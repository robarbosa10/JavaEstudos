

## JavaEstudos

Repositório onde registro minha jornada de estudos em Java. A ideia é simples: ter tudo num lugar só e conseguir olhar para trás daqui a alguns meses e ver o quanto avancei.

Cobre os fundamentos da linguagem, POO, estruturas de dados e alguns projetos práticos com Fórmula 1 como tema.

---

### O que estou aprendendo

Sintaxe, variáveis, operadores, condicionais, loops, arrays, enums, métodos, classes, encapsulamento, construtores, herança, polimorfismo, abstração, `equals()`/`hashCode()`, estruturas de dados, Collections, datas, Git e GitHub.

### 1_JavaBasico e 2_JavaBasico

Primeiros exercícios. Sintaxe básica, variáveis, tipos primitivos, operadores, `if/else`, `for`, enums e lógica. É basicamente onde tudo começou.

---

### 3_CadastroTimesBasicoPOO

Primeiro projeto tentando aplicar POO de verdade — classes, objetos, construtores, separação entre `application` e `entities`. Ainda simples, mas foi o ponto de virada para parar de pensar só em lógica sequencial.

---

### CursoEmVideoJavaPOO

Exercícios de aula cobrindo encapsulamento, relacionamento entre classes e herança. Oito aulas, cada uma com exercícios práticos.

---

### CursoEmVideoHeranca / ExPolimorfismoCursoEmVideo

Projetos separados para herança e polimorfismo — superclasses, subclasses, sobrescrita de métodos, comportamentos diferentes via mesma referência. Os conceitos que mais confundiram no começo.

---

### Ex001_POO_Sistema_Banco

Sistema bancário simples. Bom para praticar encapsulamento e regras de negócio em algo com uma lógica mais concreta.

---

### CursoJavaEstruturasdeDadosLoiane / CursoJavaLoiane / cursoJavaProfNelioAlves

Estudos seguindo os cursos da Loiane Groner e do prof. Nelio Alves. Vetores, matrizes, listas, métodos estáticos e POO. São as bases para tudo que vem depois.

---

### exerciciosHashcodeEquals

Exercícios específicos para entender como `equals()` e `hashCode()` funcionam juntos. Mais importante do que parece quando você começa a usar coleções.

---

### trabalhandoComDatas

Prática com a API de datas do Java — LocalDate, LocalDateTime, formatação, operações.

---

### ProjetosF1Estudos

A parte mais prática dos estudos. Uso Fórmula 1 como domínio porque as entidades fazem sentido intuitivo — Piloto, Equipe, Carro, Circuito, Corrida, Resultado — e consigo modelar relacionamentos reais sem inventar regras do zero.

```text
ProjetosF1Estudos/
├── formula-1-poo/
├── ProjRogerio/
└── ProjRogerioF1/
```
